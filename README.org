#+title: piano-mode
#+options: toc:nil

Turn your computer keyboard into a piano inside Emacs, with real
key-down / key-up tracking: notes keep sounding exactly as long as
you hold a key.

* Install and use
With Emacs 30 or newer, install the package and start it with:

#+begin_src elisp
(use-package piano-mode
  :vc (:url "https://github.com/tinyblinker/emacs-piano-mode")
  :custom
  (piano-audio-driver "pipewire")
  ;; (KEY . MIDI) pairs; middle C is 60.
  (piano-keys '(("a" . 60) ("w" . 61) ("s" . 62)))
  (piano-transpose 12))
#+end_src

Then run =M-x piano-play=; =M-x piano-mode= (or killing the
=*piano*= buffer) stops it.  The package needs FluidSynth, a Rust
toolchain (the bundled =piano-keys= reader is built automatically on
first use), and a SoundFont (install a system one such as
=fluid-soundfont-gm=, or set =piano-soundfont=).  Reading
=/dev/input= requires either membership in the =input= group or a
udev =uaccess= rule; without that, Emacs cannot see the keyboard
device.  If an older checkout is already installed, remove
=~/.config/emacs/elpa/piano-mode= (or run =M-x package-vc-upgrade=)
and evaluate the form again.

* How it works
=piano-keys= reads raw key state from the Linux evdev ABI under
=/dev/input=, reports key-down and key-up lines to Emacs, and Emacs
maps those keys to MIDI notes and drives one persistent FluidSynth
process.  The mapped keys are suppressed only while the =*piano*=
buffer is selected, and leaving the buffer releases every sounding
note.

* Configuration
Customize =piano-keys=, =piano-transpose=, =piano-soundfont=,
=piano-audio-driver=, =piano-keys-program=, =piano-device=, and
=piano-auto-build= with =M-x customize-group RET piano RET=.
If startup fails, check =*Messages*=: the error names the missing
SoundFont, FluidSynth, Cargo, or permission problem.
